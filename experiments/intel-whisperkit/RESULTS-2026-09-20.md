## CPU-only: no compatibility result

The runner could not connect to `github.com:443` to clone the pinned Argmax dependency.
The summary stage is `dependency_resolution`; compilation and transcription were not
reached. Its artifact upload also timed out. The diagnostic unit tests had passed.

This is a network failure. It does not establish whether CPU-only WhisperKit works
or fails on Intel, and it does not justify replacing the engine yet.

The saved `environment.json` records native `x86_64`, macOS 15.7.9, Xcode 16.4 and

not a specification or benchmark of the user's physical Mac.

`probe.log` records abnormal termination; `summary.json` records command exit `-11`,
consistent with SIGSEGV. Because the process died, the last checkpoint is intentionally
still `running`. It is NOT a successful or completed transcription.

The checkpoint establishes that model loading finished before the crash in the first
transcription operation. It does not distinguish audio conversion from individual
Core ML or decoder operations inside that call. No crash backtrace was saved. The
virtual Metal device is a possible variable, not an established cause.

## Decision

Do not repeat the two-job matrix, change models blindly, declare Intel unsupported,
or claim an engine fix from these results. The missing first comparison is CPU-only.
Prefer one local CPU-only test on the intended Intel Mac after checking its macOS,
RAM and Xcode/toolchain. If that also crashes, collect a macOS crash backtrace before
patching the inference engine. If it succeeds, measure that path before any GPU work.

manual-only, requires explicit approval, defaults to one CPU-only job rather than a
matrix, has a 20-minute overall ceiling, and retains future diagnostic artifacts for
3 days. Existing artifacts are not deleted. Other inherited workflows are unchanged:
keep repository Actions disabled until those are reviewed separately.

The workflow's YAML and safety properties were checked locally. No new native macOS
execution was performed, and no Swift, Python runner, app, or dependency code was
changed in this follow-up.
